# 인생 점수 랭킹 API

프런트는 https://api.haejeoklife.com/api/v2/rankings 를 사용한다. 기존 현상금 랭킹은 별도로 유지할 수 있다. 점수 없는 기존 기록은 새 순위 집계에서 제외한다. 날짜 기준은 한국 시간이다.

## 등록

POST /api/v2/rankings (application/json)

```json
{
  "nickname": "후샤",
  "scoreVersion": 2,
  "totalScore": 914,
  "careerPoints": 500,
  "skillPoints": 189,
  "dreamPoints": 200,
  "wealthPoints": 25,
  "bestCareer": "의사 견습 · 명성 있는 의사",
  "topSkills": [{"name":"의술","points":100},{"name":"제작","points":89}],
  "peakMoney": 1500000,
  "bounty": 0,
  "age": 68,
  "title": "바다의 명의",
  "raceAndJob": "인간 · 은퇴",
  "causeOfDeath": "노환",
  "lifeHeadline": "평생 겨뤄 온 라이벌과 화해했다."
}
```

대표 경력이 없으면 bestCareer는 빈 문자열이다. 점수가 있는 기술이 두 개 미만이면 topSkills는 해당 개수만 보낸다. 현상금과 사인은 프로필 정보다.

## 조회와 응답

GET /api/v2/rankings/today?limit=30 은 {totalCount, topRankings}를 반환한다. POST 응답은 여기에 myRank를 추가한다. topRankings 각 행은 등록 필드와 정수 rank를 포함한다. 서버가 전체 도전 기록에서 totalScore 내림차순으로 선정하고, 동점은 공동 순위(1, 1, 3)로 반환한다. 같은 점수의 표시 순서만 등록 시각과 ID로 고정한다.

## 서버 계산 기준

- scoreVersion 2는 직업 성취 보정판이다. 이전 배점(v1)·현상금 랭킹과 별도로 집계한다. 서버 API 경로는 그대로 사용한다.
- 퇴직·전직 후에도 단일 경력의 최고점만 보존한다. 직급 N단계, 0부터 시작하는 순번 i의 기본점은 100 + round(400 × i / (N−1))이다. 해군의 11단계는 차례로 100, 145, 190, 240, 280, 320, 360, 400, 440, 475, 500점이다.
- 일반 경력은 최고 직급 500점. 하위 직급은 근속 1턴당 4점(최대 100점)을 더하며 합계는 최대 490점이다. 첫 직급은 1턴당 2점(최대 50점)이다. 근속은 해당 경력의 게임 턴 기준이다. 천룡인 0~1단계는 근속 보너스가 없다. 당주 이상은 180 + 권세×2, 혁명군 정식 대원 이상은 160 + 신뢰도×2와 비교해 큰 점수를 쓴다.
- 승진으로 선장이 되거나 선장으로서 사황·해적왕을 달성한 경우 500점이다. 그 외 선장은 150 + 악명×2 + 지휘 점수. 지휘 점수는 근속턴×4와 선장 재임 중 이긴 서로 다른 강적 수×25 중 큰 값(최대 150점)이다. 강적은 기존 전투의 적 전력 60 이상이며 같은 게임 내 상대 이름은 한 번만 센다. 악명·권세·신뢰도는 0~100이다.
- 검술·무투술·항해술·요리·제작·의술·장사의 개별 최고치를 각각 100에서 제한하고 상위 두 개만 합산한다.
- 꿈 진행률이 25%, 50%, 75%에 도달하면 50, 100, 150점이다. 게임에서 완료 처리한 꿈이 있으면 200점이다. 여러 꿈 중 최고치만 사용한다.
- 생애 최고 보유액이 10만, 100만, 500만, 1천만, 3천만, 8천만 베리 이상일 때 각각 10, 25, 45, 60, 80, 100점이다. 첫 구간 미만은 0점이다.
- 총점은 네 항목의 합이다. 서버에서는 항목 범위와 합계, 기술 두 개의 중복과 합계, 재산 구간을 검증할 수 있다. 이 요청은 플레이 전체를 증명하는 데이터는 포함하지 않는다.

# 회수 사건 작성 지침 (ONE PIECE LIFE)

게임 저장소: `c:\haejeoklife` (브랜치 feat/kid-callbacks). **파일을 고치지 말고**, 맡은 회수 사건을 지정한 출력 파일 하나에 JS로 쓴다.
먼저 `c:\haejeoklife\CLAUDE.md`의 1·2·4·5·6·8·9·11절을 읽는다. 이 지침과 CLAUDE.md가 다르면 이 지침을 따른다.

## 무엇을 만드나

어린 시절(4~15세) 선택이 남긴 플래그를 보고, **최소 5년 뒤 어른이 된 주인공에게 돌아오는 회수 사건**을 쓴다.
- 플래그 하나당 회수 사건 **1개**(내용이 풍부하면 2개까지). 사건 하나 안에서 **신분별 변형(by)**으로 결과를 다르게 한다.
- 플래그를 남긴 원래 선택지는 `index.html`에서 찾아 읽는다(아래 위치). 본문에는 그때의 **장소·물건·대사** 같은 구체적인 단서를 넣는다.
  예: "그날 부두에서 손가락을 베였던 생선 칼", "모래성 꼭대기에 꽂았던 조개껍데기", 애꾸눈 해적의 "꼬마, 배 위에서 일해 볼 생각 없나?"
- **좋은 선택만 보상받지 않게**: 무심했거나 이기적이었던 선택(도망침, 고자질, 약속을 깸, 혼자 쌓음, 짐만 날라 줌 등)도 의미 있는 결과를 준다. 나쁜 결과만 주는 게 아니라 그 선택다운 결과(예: 혼자 해낸 아이 → 혼자서도 버티는 힘, 대신 곁에 아무도 없음).

## 출력 형식

출력 파일은 이 한 줄로 시작해 배열 하나를 넘긴다:

```js
CB([
  {
    key: "cb_train_sword",              // cb_ + 플래그 이름에서 f_ 뺀 것. 2개면 _a, _b
    flags: ["f_train_sword"],            // 이 플래그가 있어야 나옴
    after: 5,                            // 플래그가 생긴 뒤 최소 몇 년 (기본 5, 5 이상)
    when: { minAge: 18, maxAge: 60 },    // 턴 나이. minAge는 16 이상. 필요하면 status: ["해적", ...], notFlags
    title: "녹슨 목검의 주인",            // 6절: 명사구 4~14자, 문장부호 없음
    body: "…",                           // 6절: ~습니다체 2인칭(당신), 장면→상황→고민, 2~3문장, 100~200자. 대사는 큰따옴표 한 줄까지
    choices: [                           // 2~3개. 각 { title, desc, effect, risk?, req? }
      { title: "…한다", desc: "결과 힌트(숫자 없이 25자 이내)",
        effect: { relationship: 4, money: 30000, traits: { "선량": 1 }, flags: ["f_cb_..."], log: "명사형 기록(~함, 40자 이내)" },
        risk: { chance: 0.25, effect: { health: -8, log: "…" } } }
    ],
    by: {                                // 신분별 변형. 키는 신분을 | 로 묶는다. 맞는 첫 키를 쓰고, 없으면 "*"
      "해적|혁명군": { body: "…", choices: [ { effect: {…}, desc: "…" }, {}, { title: "…", effect: {…} } ] },
      "해군":        { body: "…", choices: [ … ] },
      "*":           { }                 // 민간인·현상금 사냥꾼 등 기본값 = 위의 기본 내용 그대로
    }
  },
  …
]);
```

- `by` 안의 `title`·`body`는 기본값을 통째로 바꾼다. `choices`는 **같은 자리(순서)끼리** 덮어쓴다: 적은 필드만 바뀌고(effect를 적으면 effect 전체가 바뀜), `{}`는 기본 그대로.
- 신분 값: `"민간인"`, `"해적"`, `"해군"`, `"혁명군"`, `"현상금 사냥꾼"`(민간인이면서 직업이 현상금 사냥꾼), `"천룡인"`. 노예와 천룡인에게는 기본적으로 안 나온다(따로 when.status에 넣으면 나옴).
- **신분별로 결과가 실제로 달라야 한다.** 최소 두 그룹(예: 바다의 무법자 "해적|혁명군" / 해군 / 기본)으로 나눈다. 4절 신분 규칙을 지킨다(해군에게 현상금, 해적에게 정부 훈장 금지 등). `bounty`는 해적·혁명군 변형에만, `standing`은 신분 평판(해적 악명·해군 공적·혁명군 신뢰도·사냥꾼 실적·민간 사회적 지위).

### 본문 끼워 넣기 (토큰)
본문·선택지·기록에 쓸 수 있다. `|조사`를 붙이면 받침에 맞는 조사가 붙는다(을/를 → `|을`, 이/가 → `|이`, 은/는 → `|은`, 와/과 → `|와`, 으로/로 → `|로`).
- `{고향}` 태어난 곳 이름, `{여기}` 지금 있는 곳 이름
- `{해적단}` 어릴 때 만난 해적단 이름(`f_kid_pirate_scout_kept`·`f_kid_stowaway` 등 pirateContact가 있을 때만. 없으면 "그 해적단")
- `{npc:모래밭의 아이}` 첫 친구 사건에서 남은 '모래밭의 아이' 이름(없으면 "그 아이"). `{단짝}` 어릴 적 단짝 이름(없으면 "옛 친구")
- 예: `"{고향|로} 돌아가는 배에서"`, `"{npc:모래밭의 아이|이} 당신을 알아봅니다."`

### effect에 쓸 수 있는 것 (CLAUDE.md 5·9절)
`health happiness knowledge relationship reputation combat money skills{"검술"…} memory log traits{"용기"|"신중"|"선량"|"야심": 1} flags[] standing bounty("+20%")`
- `log`는 필수, 명사형(~함/~음/~됨). memory는 20자 이내 명사구(선택).
- 성향은 이 네 가지뿐. 선택지마다 성향 하나를 `traits`로 적는다.
- 회수 사건이 나왔다는 표시는 게임이 자동으로 남긴다. 따로 적지 않는다. 다음 회수로 이어 갈 만하면 `flags: ["f_cb_…"]`를 남겨도 된다.

## 수치 (어른 기준, CLAUDE.md 2절)
회수 사건은 "인생에 몇 번 있는 일"이라 **중** 등급이 기본, 인생을 바꿀 만한 것만 대.
| 스탯 | 소 | 중 | 대 |
| 건강 | ±1~5 | ±6~15 | ±16~30 |
| 행복 | ±1~5 | ±6~10 | ±11~20 |
| 지식 | +1~3 | +4~6 | +7~12 |
| 관계 | ±1~4 | ±5~6 | ±7~10 |
| 전투력 | +1~3 | +4~8 | +9~15 |
| 명성 | ±1~5 | ±6~10 | ±11~20 |
| standing | +1~4 | +5~8 | +9~15 |
| 기술 | +1~4 | +5~10 | +11~20 |
| 돈 | 1만~3만 | 6만~65만 | 65만~650만 |
| 현상금 | +5~15% | +20~50% | +50~200% |
- 한 선택지에서 같은 등급을 두 개 넘게 쌓지 않는다. risk chance는 0.1~0.4.

## 재미있는 선택 (CLAUDE.md 8절) — 반드시
- 선택지 2~3개, 서로 다른 가치(안전/위험, 나/남, 지금/나중, 원칙/실리, 돈/관계)를 건다. 제목만 읽어도 성격이 보이게.
- **모든 면에서 나은 선택지 금지.** 선택지마다 잃는 것이 있다. 최소 하나는 명시적인 대가(줄어드는 스탯)나 risk.
- 효과 없는 선택지 금지. 착한 선택 vs 나쁜 선택 구도 금지.
- 원작 대사·장면을 옮기지 않는다. 원작 인물은 배경으로만.
